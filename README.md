# Netram Eye Care - Official Clinic Website

Modern, high-performance website for **Netram Eye Care & Cornea Centre** (Bhopal), led by **Dr. Siddharth Malaiya** [MS (Ophth.), FLVPEI (Hyd.)].

## 🌟 Key Features

- **Interactive Scroll-Driven Eye Background**: 240 high-definition frames of a human eye smoothly opening as the patient scrolls through the clinic offerings and doctor credentials.
- **Adaptive Mobile Geometry**: Automatic portrait detection that centers the eye directly on mobile screens for an optimal viewing experience on smartphones.
- **Service Highlights**:
  - Advanced Cataract & Refractive Surgery (MICS, Phacoemulsification, Premium Toric & Multifocal IOLs)
  - Specialized Cornea & Anterior Segment Care (Corneal Transplants, Keratoconus, C3R)
  - Glaucoma Screening & Management
  - Comprehensive Diagnostic Suite & Dry Eye Management
- **One-Click Patient Actions**: Direct WhatsApp booking and phone call consultation links.
- **Medical Trust & Compliance**: Real clinic credentials, verified clinic location on Kolar Road, Bhopal, and transparent practice timings.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animation**: Custom HTML5 Canvas rendering engine with Lerp interpolation & priority frame preloader
- **Icons**: Lucide React
- **Language**: TypeScript

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17+ or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nagarkamlesh549-sys/clinic-.git
   cd clinic-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
